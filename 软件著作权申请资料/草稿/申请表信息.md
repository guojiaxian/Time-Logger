➤软件的主要功能：面向地震密集台阵设备一致性检测作业的现场记录工具，通过监听设备麦克风自动识别锤击地表时产生的瞬态声波，精确定位敲击起始时刻并以高精度北京时间落账，把声学敲击测量现场转换成可导出、可备份、可追溯的高精度时间数据。软件基于 Web Audio API 监听设备麦克风，主要提供以下功能：一是自动检测并记录敲击时刻，点击开始记录后持续监听声波峰值，当超过触发阈值且处于防重复间隔之外时判定为一次敲击，捕获起始样本、补偿音频链路延迟后写入精确北京时间；二是高精度北京时间显示与记录，秒值小数位2至6位可配置，并支持附加时间补偿毫秒数以修正链路延迟；三是实时声音信号电平可视化与过强提示，记录页实时绘制峰值电平曲线并叠加触发阈值虚线，信号过强时提示移远敲击点；四是记录即时管理，支持手动补记、撤销单条、一键清空当前记录；五是当前会话一键导出 .dat 时间戳文件，每行一条时间戳，精度与设置保持一致；六是历史会话分组管理与全部导出、删除，会话按最新在前展示，各会话以注释行分隔；七是停止记录后自动增量同步备份，将新增敲击与会话按设备上传至服务器，分批上传并带 SHA-256 完整性校验、失败退避重试与断网续传，同步状态通过状态灯、进度条、待同步计数与可展开日志呈现；八是声音阈值校正，先测量环境噪音基线再采集敲击样本，按信噪比计算并持久化最佳触发阈值，解决误触发或敲击不触发的问题。数据以 IndexedDB 本地持久化、断网可用，旧版本记录自动迁移。软件作为便携的高精度敲击时刻记录仪，免手动掐表、免笔记录，可一键导出数据并备份到服务器，显著提升现场台阵设备一致性检测的效率和准确率。
➤软件的技术特点：基于 Web Audio API 的麦克风瞬态声波自动检测与高精度北京时间记录；IndexedDB 持久化与增量水位同步、SHA-256 完整性校验；纯前端单页架构与零依赖 Node 服务端。
