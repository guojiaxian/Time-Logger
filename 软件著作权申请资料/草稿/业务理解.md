# 业务理解

- 软件名称：台阵设备一致性检测时间记录器
- 产品定位：面向地震密集台阵设备一致性检测作业的现场记录工具，通过监听设备麦克风自动识别锤击地表时产生的瞬态声波，精确定位敲击起始时刻并以高精度北京时间落账，把声学敲击测量现场转换成可导出、可备份、可追溯的高精度时间数据。
- 面向领域 / 行业：地震观测 / 地球物理探测 / 工程检测辅助
- 核心价值：把手机或安卓终端变成一台便携的高精度敲击时刻记录仪，自动检测敲击并记录到毫秒级、秒值小数最高6位的北京时间，免手动掐表、免笔记录，数据本地持久化并可一键导出 .dat 与增量备份到服务器，极大提升现场一致性检测的效率和准确率。
- 证据文件：`业务理解证据.md`

## 目标用户

- 地震台阵运维与检测人员
- 物探现场作业人员
- 通过锤击法对多台设备做一致性检验并记录精确敲击时刻的技术工程师

## 主要业务功能

- 基于麦克风瞬态声波自动检测并记录敲击时刻
- 高精度北京时间显示与记录，秒值小数位2-6位可配置
- 实时声音信号电平可视化与过强提示
- 手动补记、撤销单条、一键清空当前记录
- 当前会话一键导出 .dat 时间戳文件
- 历史会话分组管理与全部导出/删除
- 停止记录后自动增量同步备份与完整性校验
- 声音阈值校正
- 网络校时、附加时间补偿与防重复间隔等精细校准
- 本地持久化与深浅色主题等体验能力

## 功能说明

- 基于麦克风瞬态声波自动检测并记录敲击时刻：进入记录页点击开始记录，软件通过 Web Audio API 打开麦克风，持续监听声波峰值，当超过触发阈值且处于防重复间隔之外时判定为一次敲击，捕获起始样本、补偿音频链路延迟后写入精确北京时间。
- 高精度北京时间显示与记录，秒值小数位2-6位可配置：时间显示采用北京时间 UTC+8，秒值小数位在2至6位之间可配置，附加时间补偿以毫秒为单位，正值延后、负值提前，满足不同精度要求的检测口径。
- 实时声音信号电平可视化与过强提示：记录页实时绘制声音信号峰值电平曲线，叠加触发阈值红色虚线，信号过强时给出提示建议将设备移远敲击点以免精度下降。
- 手动补记、撤销单条、一键清空当前记录：敲击记录按时间正序展示并支持即时操作，自动漏判时手动补记一条、出现误判时撤销最近一条、整段需重录时一键清空当前会话，每条记录都能看到精确时刻。
- 当前会话一键导出 .dat 时间戳文件：当前会话可导出为纯文本 .dat 文件，每行一条时间戳，秒值精度与设置保持一致，文件名带所设前缀与导出时刻，可直接用于后续数据处理软件。
- 历史会话分组管理与全部导出/删除：每次开始到停止记录存为一条会话，历史视图按最新在前展示，可逐条导出、批量导出全部并删除不需要的记录，导出全部时各会话以注释行分隔。
- 停止记录后自动增量同步备份与完整性校验：停止记录后自动将新增敲击与会话增量上传到服务器，按设备落盘；上传分批进行并带 SHA-256 完整性校验、失败退避重试与断网续传，同步状态通过状态灯、进度条、待同步计数和可展开日志呈现。
- 声音阈值校正：在设置页点击校正声音阈值，软件先测量环境噪音基线，再采集用户敲击样本，按信噪比计算并持久化最佳触发阈值，解决误触发频繁或敲击不触发的问题。
- 网络校时、附加时间补偿与防重复间隔等精细校准：提供网络校时功能校准北京时间，可设置附加补偿毫秒数修正链路延迟，并调节防重复间隔避免回声与余振重复记录；默认使用手机系统时间。
- 本地持久化与深浅色主题等体验能力：数据以 IndexedDB 本地持久化，断网可用，旧版本 localStorage 记录自动迁移；支持深浅色主题一键切换并持久保存，可部署为 PWA 或安卓离线 APK。

## 典型操作流程

1. 部署或打开软件：手机浏览器打开 Web 版，或安装并启动 APK 离线版
2. 设置检测参数：在设置视图调节触发阈值、防重复间隔、导出精度、文件名前缀、附加补偿；必要时校正声音阈值或网络校时
3. 进入记录视图，点击开始记录并授权麦克风，观察电平表确认信号正常
4. 在检测点敲击地面，软件自动捕获每次敲击并实时显示累计次数与最近时刻
5. 记录完成后点击停止记录，软件自动将本会话存入 IndexedDB 并触发增量同步备份
6. 在记录视图或历史视图一键导出 .dat 时间戳文件，或到历史视图导出全部会话、查看同步状态与日志

## 操作手册结构建议

1. 本软件是针对地震密集台阵设备一致性检测场景的现场敲击时刻记录工具，用户在检测点用锤敲击地面，软件自动记录每次敲击的精确时刻。
2. 软件按记录、历史、设置三个视图组织功能，底层标签栏切换，手机浏览器与安卓 APK 均可使用并保持一致交互。

## 操作手册页面/流程模块

1. 开始与结束一次敲击记录：底部导航点「记录」，点击页面主按钮「开始记录」。
   - 使用场景：检测人员到达测点、麦克风已连接且手机亮屏时，准备用锤敲击地面并记录全程敲击时刻。
   - 操作要点：在记录视图确认提示授权麦克风，观察电平表有信号波动；点击「开始记录」按钮，按钮变为停止并开始累计敲击；保持手机靠近声源并按节奏敲击地面，观察实时计数与最近记录时刻更新；敲击完成后点击停止记录按钮，会话结束并自动保存与同步
2. 查看敲击信号电平与过强提示：记录视图电平表区域，无需额外操作即可看到实时曲线。
   - 使用场景：敲击不触发或频繁误触发时，用户观察电平曲线辅助定位问题。
   - 操作要点：在记录视图观察电平曲线，正常敲击应有明显峰值越过红色虚线；信号过强时读取提示，将手机适当移远敲击点后再次敲击验证；敲击持续不触发时到设置视图调节阈值或执行阈值校正
3. 手动补记、撤销与清空记录：记录视图底部按钮行，分别为「手动补记」「撤销一条」「清空」。
   - 使用场景：自动检测遗漏了极轻的一次敲击、误记录了一次非敲击声音，或整段记录需要重来。
   - 操作要点：自动漏记时点击「手动补记」，立刻写入一条当前时刻记录；列表出现无用的误判记录时点击「撤销一条」移除最近一条；整段记录错乱时点击「清空」移除本次会话所有记录；操作后到记录列表核对条数与时序
4. 导出当次敲击记录为 .dat 文件：记录视图底部「一键导出 .dat 文件」按钮，或历史视图「导出全部会话」。
   - 使用场景：一次检测会话完成后，需要把敲击时刻数据交给分析软件处理。
   - 操作要点：确认记录列表中的时间戳精度、前后缀符合要求；点击「一键导出 .dat 文件」，浏览器开始下载以文件名前缀+时间戳命名的文件；文件内每行一条时间戳，按设置精度输出；到历史视图可点击「导出全部会话」合并导出所有历史数据
5. 管理历史会话与批量导出：底部导航点「历史」进入历史会话列表。
   - 使用场景：现场作业结束后，需要整理某一段时间内全部会话数据或清理不需要的历史记录。
   - 操作要点：在历史视图浏览按最新在前的会话列表，查看每条会话的开始结束时间、敲击数与时长；点击会话的导出入口导出单条，或点「导出全部会话」合并导出；在数据同步卡片查看同步状态，待同步计数不为0时可点击「立即同步」；展开同步日志查看每次同步结果，删除不需要的历史会话
6. 同步数据到服务器备份：历史视图的数据同步卡片；停止记录后也会自动触发。
   - 使用场景：需要在现场记录完成后把数据统一汇总到服务器，多设备数据按设备分开存放。
   - 操作要点：在设置视图确认同步服务器地址正确（网页版自动填入当前站点，APK需手动填写）；正常记录后软件自动同步，也可在历史视图点击「立即同步」；通过状态灯、进度条和待同步计数观察同步进度；展开同步日志查看每次上传结果，按需排查失败重试情况
7. 设置检测与导出参数：底部导航点「设置」进入检测与导出设置。
   - 使用场景：环境噪声不同导致误触发，或不同检测任务对时间戳精度要求不同时调整参数。
   - 操作要点：调节「触发阈值」滑动条，结合电平表确认灵敏度合适；调节「防重复间隔」避免回声与余振重复记录；选择「导出与记录精度」的秒值小数位，设置「导出文件名前缀」；按需填写同步地址、附加时间补偿，或点击网络校时校准北京时间
8. 校正声音触发阈值：设置视图点击「校正声音阈值」按钮弹出校正窗口。
   - 使用场景：系统监听阈值不适应当前环境导致漏触发或误触发，手动调阈值无效时使用。
   - 操作要点：在设置视图点击「校正声音阈值」打开校正弹窗；按提示静置手机测量环境噪音基线，观察强度曲线；按引导在声源处敲击采样，点击「我已敲击·确认」；查看算出的阈值结果，可点「测试」验证是否仍需调整
9. 校准网络时间与深浅色主题：设置视图「时间校准」区域点「网络校时」；顶部标题栏主题切换按钮。
   - 使用场景：手机系统时间不确定时校准，或在夜晚/强光现场切换主题获得更好的可视性。
   - 操作要点：在设置视图点击「网络校时」，读取校时结果与延时；确认校准后记录页时钟与日期星期同步更新；点击顶部主题按钮在深色与浅色间切换；确认选择并保存，刷新页面不闪变
