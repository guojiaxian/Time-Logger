# 台阵设备一致性检测时间记录器操作手册

## 一、说明

台阵设备一致性检测时间记录器 V1.0适用于地震观测 / 地球物理探测 / 工程检测辅助场景。软件通过监听设备麦克风自动识别锤击地面时产生的瞬态声波，为每次敲击记下精确到毫秒级（秒值小数最高 6 位）的北京时间，供地震台阵设备一致性检测使用。

日常使用时，地震台阵运维与检测人员、物探现场作业人员、通过锤击法对多台设备做一致性检验并记录精确敲击时刻的技术工程师，在检测点用锤敲击地面，软件在记录页实时累计敲击次数并记录精确时刻；记录结束后一键导出 .dat 时间戳文件，或自动把新增数据增量备份到服务器，避免数据因设备丢失而丢失。

本手册用于说明软件的用途、功能特点、运行要求和页面操作流程。各功能章节按用户能够看到的页面、入口、按钮、输入项、提示信息和处理结果进行说明。

## 二、功能特点

软件围绕「记录敲击时刻」这一核心任务，把记录、历史、设置三个视图放在底部导航栏，用户一键切换即可完成从开始记录、查看结果到导出备份的完整流程。

在记录视图，用户点击开始记录并授权麦克风后，软件实时累计敲击次数并更新最近记录时刻，同时以电平曲线直观显示声音信号强弱；支持手动补记漏判、撤销误判和清空重来，并可一键导出当次记录为 .dat 时间戳文件。

在历史视图，所有完成记录的会话按最新在前排列，用户可以查看每次会话的时间范围、敲击数与时长，逐条或全部导出，并可集中查看数据同步状态、进度、待同步计数和同步日志。

在设置视图，用户可以按现场环境调节触发阈值、防重复间隔等检测参数，选择导出精度与文件名前缀，校正声音阈值解决误触发或漏触发问题，并进行网络校时、附加时间补偿校准、深浅色主题切换。

数据全程保存在本机 IndexedDB，断网也可用；每次停止记录后自动把新增数据增量同步到服务器，带完整性校验与断网续传，保证现场采集的数据安全。

## 三、系统要求

| 系统要求 | 最低配置 | 推荐配置 |
| --- | --- | --- |
| 操作系统 | Android 8.0 及以上或任意支持现代浏览器的系统 | Android 10 及以上，用于运行 APK 客户端 |
| 服务端运行环境 | Node.js 14 以上、OpenSSL（用于自签名 HTTPS 证书） | Node.js 16 及以上 |
| 浏览器 | 支持 Web Audio API 与 IndexedDB 的现代浏览器 | 新版 Chrome / Android 系统浏览器 |

| 存储 | 本地 IndexedDB 可用，便于数据保存 | 预留充足本地存储用于多会话记录 |

请确保实际运行环境满足以上要求，以保证台阵设备一致性检测时间记录器能够正常打开页面、提交操作和展示处理结果。若部署方式、客户端形态或服务器环境与本表不同，应以实际确认的申请表环境字段为准。

## 四、开始与结束一次敲击记录

开始与结束一次敲击记录用于在检测点开启一段检测会话，自动捕获每次敲击并最终结束会话保存数据。用户通过底部导航点「记录」，点击页面主按钮「开始记录」即可进入。

检测人员到达测点、麦克风已连接且手机亮屏时，准备用锤敲击地面并记录全程敲击时刻。

用户在开始与结束一次敲击记录页面会看到实时北京时间大时钟、日期星期、已记录敲击数与最近时刻、声音电平曲线、开始/停止记录主按钮、手动补记/撤销/清空按钮、导出按钮、当次敲击记录列表等信息，并可依据页面显示继续处理。

使用该功能时，用户先在记录视图确认提示授权麦克风，观察电平表有信号波动，随后点击「开始记录」按钮，按钮变为停止并开始累计敲击，接着保持手机靠近声源并按节奏敲击地面，观察实时计数与最近记录时刻更新，之后敲击完成后点击停止记录按钮，会话结束并自动保存与同步，最后记录过程中点击电平表下方的提示按需调整位置避免过强。

页面会按照需在 HTTPS 安全上下文或 APK 中才能访问麦克风、麦克风权限未授权时无法开始记录和防重复间隔内同一时刻只记录一次等规则限制或提示用户。处理结束后，用户可以看到开始后按钮变为「停止记录」，计数与最近时刻随敲击实时更新和停止后列表保留本次记录，数据自动存入本机并触发同步。

## 五、查看敲击信号电平与过强提示

查看敲击信号电平与过强提示页面让用户直观看到声音信号强度，判断敲击是否被正常捕获以及是否需要调整设备位置。用户可以通过记录视图电平表区域，无需额外操作即可看到实时曲线。

敲击不触发或频繁误触发时，用户观察电平曲线辅助定位问题。

该部分提供声音信号电平(峰值)标题、待机/监听状态指示灯、峰值电平曲线画布、悬浮的触发阈值红色虚线、信号过强提示文字等页面内容，用户可据此查看状态、填写信息或选择下一步操作。

在该页面中，用户先在记录视图观察电平曲线，正常敲击应有明显峰值越过红色虚线，随后信号过强时读取提示，将手机适当移远敲击点后再次敲击验证，最后敲击持续不触发时到设置视图调节阈值或执行阈值校正。

如果不满足信号过强时提示定位精度可能下降等要求，用户需要根据页面提示调整后再继续。页面反馈通常包括每次敲击对应曲线出现明显峰值和过强时出现建议移远的提示文字。

## 六、手动补记、撤销与清空记录

手动补记、撤销与清空记录用于在自动检测漏判或有误时，让用户手动补齐一条记录、撤销误判或一键清空本次记录。用户通过记录视图底部的「手动补记」「撤销一条」「清空」按钮进行操作。

自动检测遗漏了极轻的一次敲击、误记录了一次非敲击声音，或整段记录需要重来。

页面上主要呈现手动补记、撤销一条、清空三个按钮及当前敲击记录列表等内容，这些内容用于帮助用户确认当前位置和可执行操作。

实际操作时，用户先自动漏记时点击「手动补记」，立刻写入一条当前时刻记录，随后列表出现无用的误判记录时点击「撤销一条」移除最近一条，接着整段记录错乱时点击「清空」移除本次会话所有记录，最后操作后到记录列表核对条数与时序。

操作过程中需要注意清空前建议先确认是否已导出或备份和撤销仅移除最近一条。操作完成后，系统会显示手动补记后列表与计数各加一条、撤销后最近一条消失和清空后列表与计数归零。

## 七、导出当次敲击记录为 .dat 文件

导出当次敲击记录为 .dat 文件用于把本次会话的敲击时间戳输出为纯文本文件，供后续数据处理使用。用户通过记录视图底部「一键导出 .dat 文件」按钮导出，也可在历史视图点击「导出全部会话」。

一次检测会话完成后，需要把敲击时刻数据交给分析软件处理。

用户在导出当次敲击记录为 .dat 文件页面会看到导出按钮，以及导出后浏览器/系统的下载保存提示等信息，并可依据页面显示继续处理。

使用该功能时，用户先确认记录列表中的时间戳精度、前后缀符合要求，随后点击「一键导出 .dat 文件」，浏览器开始下载以文件名前缀+时间戳命名的文件，接着文件内每行一条时间戳，按设置精度输出，最后到历史视图可点击「导出全部会话」合并导出所有历史数据。

页面会按照导出精度与设置里的秒值小数位一致和文件名包含所设前缀与导出时刻等规则限制或提示用户。处理结束后，用户可以看到触发下载，得到 .dat 纯文本文件，内容为逐条时间戳。

## 八、管理历史会话与批量导出

管理历史会话与批量导出用于集中查看以往每次记录的会话，进行导出或删除管理，并掌握数据同步情况。用户通过底部导航点「历史」进入历史会话列表。

现场作业结束后，需要整理某一段时间内全部会话数据或清理不需要的历史记录。

该部分提供历史会话数量、会话列表（每条含时间范围、敲击数、时长）、导出全部按钮、各会话的导出/删除入口、数据同步状态、进度条、待同步计数、立即同步与同步日志等页面内容，用户可据此查看状态、填写信息或选择下一步操作。

在该页面中，用户先在历史视图浏览按最新在前的会话列表，查看每条会话的开始结束时间、敲击数与时长，随后点击会话的导出入口导出单条，或点「导出全部会话」合并导出，接着在数据同步卡片查看同步状态，待同步计数不为0时可点击「立即同步」，最后展开同步日志查看每次同步结果，删除不需要的历史会话。

如果不满足导出全部会话时各会话以注释行分隔等要求，用户需要根据页面提示调整后再继续。页面反馈通常包括会话数据导出为 .dat 文件、待同步清零且状态灯转绿表示同步完成和删除后列表相应减少。

## 九、同步数据到服务器备份

同步数据到服务器备份用于把本机已记录的敲击与会话单向增量备份到指定服务器，保证数据不因设备丢失或损坏而丢失。用户通过历史视图的数据同步卡片操作，停止记录后软件也会自动触发同步。

需要在现场记录完成后把数据统一汇总到服务器，多设备数据按设备分开存放。

页面上主要呈现同步状态灯(检查中/待同步/同步中/已同步等)、进度条、待同步敲击与会话条数、立即同步按钮、可展开的同步日志等内容，这些内容用于帮助用户确认当前位置和可执行操作。

实际操作时，用户先在设置视图确认同步服务器地址正确（网页版自动填入当前站点，APK需手动填写），随后正常记录后软件自动同步，也可在历史视图点击「立即同步」，接着通过状态灯、进度条和待同步计数观察同步进度，最后展开同步日志查看每次上传结果，按需排查失败重试情况。

操作过程中需要注意同步为单向客户端到服务器、仅上传新增或修改的数据和同步需可达服务器且令牌匹配(如启用)。操作完成后，系统会显示待同步计数归零、状态灯变绿、进度条走满，日志记录同步成功和断网时自动保留待同步并在恢复后续传。

## 十、设置检测与导出参数

设置检测与导出参数页面让用户按现场环境与精度要求调整触发灵敏度、防重复、导出精度等参数。用户可以通过底部导航点「设置」进入检测与导出设置。

环境噪声不同导致误触发，或不同检测任务对时间戳精度要求不同时调整参数。

用户在设置检测与导出参数页面会看到触发阈值滑块及数值、声音阈值校正按钮、防重复间隔滑块、导出/记录精度选择、导出文件名前缀输入、同步令牌、同步服务器地址、附加时间补偿、网络校时按钮等等信息，并可依据页面显示继续处理。

使用该功能时，用户先调节「触发阈值」滑动条，结合电平表确认灵敏度合适，随后调节「防重复间隔」避免回声与余振重复记录，接着选择「导出与记录精度」的秒值小数位，设置「导出文件名前缀」，最后按需填写同步地址、附加时间补偿，或点击网络校时校准北京时间。

页面会按照触发阈值取值范围约0.02~0.95、防重复间隔约100~2000ms、精度限2~6位和文件名前缀最长约40字符等规则限制或提示用户。处理结束后，用户可以看到参数即时保存到本地，下次打开保持不变和阈值变化的提示会结合电平表生效。

## 十一、校正声音触发阈值

校正声音触发阈值用于针对误触发频繁或敲击不触发的问题，自动测量环境噪音基线与敲击样本，按信噪比计算并保存最佳触发阈值。用户通过设置视图点击「校正声音阈值」按钮弹出校正窗口。

系统监听阈值不适应当前环境导致漏触发或误触发，手动调阈值无效时使用。

该部分提供校正弹窗内的阶段提示、实时声音强度曲线、提示文字、已敲击确认/测试/取消按钮、校正后的阈值数值等页面内容，用户可据此查看状态、填写信息或选择下一步操作。

在该页面中，用户先在设置视图点击「校正声音阈值」打开校正弹窗，随后按提示静置手机测量环境噪音基线，观察强度曲线，接着按引导在声源处敲击采样，点击「我已敲击·确认」，之后查看算出的阈值结果，可点「测试」验证是否仍需调整，最后点击取消丢弃或确认保存校正后的阈值。

如果不满足环境噪音过高时提示需先降低噪音再校正、敲击强度不足时提示重新采样和校正结果阈值写入本地配置等要求，用户需要根据页面提示调整后再继续。页面反馈通常包括弹窗展示由基线信噪比计算出的最佳阈值并持久化，记录页据此调整触发灵敏度。

## 十二、校准网络时间与深浅色主题

校准网络时间与深浅色主题用于保证软件记录时间以准确的北京时间为基准，并让界面在昼夜不同观看环境下都清晰易读。点击网络校时可用网络时间源校准本机时钟，降低系统时间偏差对敲击时刻精度的影响；切换深色与浅色主题可适配白天强光或夜间暗光现场。用户通过「设置」视图「时间校准」区域的「网络校时」按钮完成校时，主题切换在应用顶部的太阳/月亮图标按钮。

现场检测前若担心手机系统时间偏差较大，先做一次网络校时再开始记录；夜间或强光环境下则切换主题避免界面刺眼或看不清。

页面上主要呈现网络校时按钮及校时状态提示（偏移量、往返延时）、校时前后记录页时钟与日期星期、顶部标题栏的深/浅色主题切换按钮和主题切换后整体界面配色变化等内容，这些内容用于帮助用户确认当前位置和可执行操作。

实际操作时，用户先在设置视图滚动到「时间校准」，点击「网络校时」按钮，随后等待软件向时间源发起请求并返回校准结果，读取显示的时间偏移与往返延时，接着切回记录视图，确认顶部的北京时间大时钟与日期星期已按校准结果刷新，之后点击顶部标题栏的主题按钮，在深色与浅色之间切换，观察界面配色即时变化，最后确认所选主题在刷新页面后仍保持不变，便于持续使用。

操作过程中需要注意网络校时依赖设备能访问时间服务器，离线或无网络时无法完成校时、校时仅校准本地时间基准，不影响已保存记录数据和主题选择会持久保存，刷新不丢失。操作完成后，系统会显示点击校时后，按钮下方会显示本次校时的结果，包括与时间源的偏移量及往返延时和记录页时钟随之更新。切换主题后整个界面配色即时变化，且刷新后保持所选项。

## 十三、典型使用流程

一次典型的一致性检测记录流程如下：先打开软件并完成初始化，再设置检测参数，然后在检测点开始记录并按序敲击，最后结束记录并导出或同步数据。

具体步骤为：手机浏览器打开 Web 版，或安装并启动 APK 离线版；在设置视图调节触发阈值、防重复间隔、导出精度、文件名前缀、附加补偿，必要时校正声音阈值或网络校时；进入记录视图，点击开始记录并授权麦克风，观察电平表确认信号正常；在检测点敲击地面，软件自动捕获每次敲击并实时显示累计次数与最近时刻；敲击完成后点击停止记录，软件自动保存本会话并触发数据同步，再按需导出一键 .dat 文件或在历史视图导出一段时间的全部数据。

## 十四、常见问题解答

问题：为什么手机浏览器打开没有声音信号？
解决方法：需在 HTTPS 安全上下文（本地服务器提供服务，使用自签名证书）或 APK 中运行，并授予麦克风权限。

问题：偶尔敲击没被记录怎么办？
解决方法：观察电平表峰值是否越过阈值虚线，适当调低触发阈值或执行声音阈值校正；也可用手动补记补齐。

问题：敲击一次却记录多次？
解决方法：多为回声或地面余振，可适当调大防重复间隔。

问题：数据会丢吗？
解决方法：数据保存在本机 IndexedDB，断网也保留；停止记录后自动增量同步到服务器，多一份备份。

问题：.dat 文件里的时间精度为什么是 2~6 位？
解决方法：可在设置里选择秒值小数位，最高6位，与记录和导出保持一致。

## 十五、术语表

| 术语 | 解释 |
| --- | --- |
| 触发阈值 | 判定一次敲击的声音信号峰值幅度门槛，值越小越灵敏。 |
| 防重复间隔 | 一次敲击后被忽略的时间窗，用于防止回声与余振重复记录。 |
| 会话 | 从点击开始记录到停止记录之间的一次完整检测过程，含起止时间、敲击数等。 |
| .dat | 纯文本数据文件，每行一条时间戳，可直接用于后续处理。 |
| 水位同步 | 按敲击 id 与会话更新时间记录同步进度，只上传新增或修改数据的增量同步。 |
| SHA-256 | 用于数据完整性校验的哈希算法，同步前后比对校验。 |
